# Support

## Getting Help

- **Issues**: File a bug report or feature request at https://github.com/krsatyam36/esp32-s3/issues
- **Discussions**: Join the GitHub Discussions for Q&A and community help
- **Documentation**: See [README.md](README.md) for setup and usage guides
- **Changelog**: See [CHANGELOG.md](CHANGELOG.md) for release history

## Troubleshooting

Before opening an issue:
1. Run `make check` to validate your setup
2. Check [Troubleshooting section](README.md#troubleshooting) in README
3. Search existing issues for similar problems
4. Ensure your ESP32 is on the same WiFi network

## Reporting Bugs

Include:
- ESP32 firmware version (from serial output)
- Python version (`python --version`)
- Full error output
- Steps to reproduce
